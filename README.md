# ✨ 밤하늘 상상 연구소 — 나만의 별자리 만들기

초등학교 4학년 과학 ‘밤하늘 관찰’의 창의적 확장 활동용 정적 웹앱입니다.
별을 직접 배치하고 연결한 뒤, 모양을 상상하고 이름과 이야기를 남깁니다.

## 바로 실행하기

1. ZIP 파일의 압축을 모두 풉니다.
2. `index.html`을 PC Chrome으로 엽니다.
3. 학생 수업에는 아래 방법으로 만든 GitHub Pages 주소를 공유합니다.

별도 설치, npm, 빌드, Google 로그인, Firebase, 외부 API가 필요하지 않습니다. 폴더 안의 파일만으로 작동합니다.

## GitHub Pages에 올리기

1. GitHub에 새 저장소를 만듭니다. 예: `constellation-lab`.
2. 일반적인 GitHub Free 계정은 **Public** 저장소를 선택합니다.
3. **Add file → Upload files**에서 압축을 푼 **폴더 안의 파일과 하위 폴더 전체**를 올립니다. ZIP 자체를 올리지 마세요.
4. **Commit changes**로 저장합니다. 저장소 첫 화면에 `index.html`, `css`, `js`, `assets`가 있어야 합니다.
5. **Settings → Pages**로 이동합니다.
6. **Source: Deploy from a branch**, **Branch: main**, **폴더: /(root)**를 선택하고 **Save**를 누릅니다.
7. 배포가 완료되면 같은 화면에 표시되는 웹사이트 주소를 학생들에게 공유합니다. 학생은 GitHub에 로그인할 필요가 없습니다.

주소 형식 예시: `https://사용자이름.github.io/constellation-lab/`
실제 주소는 본인 저장소의 Pages 화면에서 확인하세요.

[GitHub 공식 게시 설정 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

이 파일은 GitHub 업로드용 코드입니다. 사용자 계정에 실제 업로드하거나 배포한 것은 아닙니다.

## 파일 구성

| 파일/폴더 | 역할 |
| --- | --- |
| `index.html` | 웹앱 시작 파일 |
| `css/style.css` | 반응형 화면 |
| `js/model.js` | 별·연결선·스케치 데이터 처리 |
| `js/app.js` | 단계별 활동과 마우스·터치 조작 |
| `js/export.js` | 작품을 1600 × 1000 PNG로 그리는 기능 |
| `assets/` | 아이콘과 글꼴 등 로컬 자산 |
| `.nojekyll` | 정적 파일 배포 표시 |
| `TEACHER_GUIDE.md` | 수업 운영과 조작 안내 |
| `VALIDATION.md` | 검증한 내용과 범위 |

경로가 모두 상대 경로이므로 GitHub Pages의 저장소 하위 주소에서도 사용할 수 있습니다. Vercel에서도 정적 파일로 배포할 수 있는 구조입니다.

## 지원하는 기능

- 카시오페이아자리의 점과 연결선을 짧게 관찰
- 밤하늘을 눌러 별 추가, 최대 15개
- 마우스/손가락 드래그 이동, 이동 중 연결선 반영
- 별을 차례로 눌러 연속 연결, 중복·자기 자신 연결 방지
- 별 삭제 시 해당 연결선도 삭제, 연결선만 선택해서 삭제
- 실행 취소·다시 실행 50단계 (현재 탭에서의 도형 편집)
- 별마다 흰색·노란색·주황색·붉은색·푸른색 선택 (별을 누르면 아래에 색깔 버튼 표시, 고른 색으로 계속 별 놓기)
- 별 크기·밝기 3단계
- 선택형 자유 스케치, 한 획씩 지우는 스케치 지우개
- 별 4개 이상이 하나로 이어지면 상상 질문 표시
- 정답이나 완성 예시를 주지 않는 무작위 상상 질문
- 이름·모습·만든 사람 작성, 선택형 이야기
- 완성 화면에서 작품 확인 후 이미지 저장
- localStorage 자동 저장과 초기화 확인창
- 메뉴 없는 1600 × 1000 작품 PNG 저장

## 저장 방식

작품은 이 기기·브라우저·웹사이트 경로의 localStorage에 저장됩니다. 별 위치·색깔·크기·밝기·연결·스케치·이름·모습·이야기·만든 사람이 저장됩니다. 새로고침하면 현재 단계와 작품, 새로 놓을 별의 색이 복원됩니다. 실행 취소 이력은 현재 탭에서만 유지됩니다.

시크릿 모드 종료, 사이트 데이터 삭제, 다른 기기·브라우저로 이동하면 기록을 이어 볼 수 없습니다. 같은 태블릿을 다음 학생이 사용하기 전에 ‘처음부터 만들기’를 누르세요. 기록은 서버로 보내지 않습니다.

‘내 별자리 이미지 저장’은 완성 작품을 PNG로 만듭니다. PNG에는 별자리 연결선·스케치·이름·설명이 모두 포함됩니다. 파일 다운로드가 시작되지 않으면 화면 아래의 ‘저장이 안 되면…’을 펼치고 이미지를 길게 누르거나 PNG 다시 저장을 누릅니다.

완성 화면에는 이미지 저장 버튼만 표시됩니다. 수정하려면 상단 활동 단계에서 돌아갈 수 있습니다. 작품을 다른 기기로 옮기려면 저장한 PNG 파일을 전달하세요.

## 자주 묻는 문제

- **404가 나와요:** 저장소 최상위에 `index.html`이 있는지, Pages가 `main / (root)`인지 확인하세요.
- **화면이나 버튼이 이상해요:** `css`, `js`, `assets` 폴더까지 모두 올렸는지 확인하세요.
- **별을 못 움직여요:** ‘별 놓기’ 또는 ‘선택·이동’ 도구에서 별을 끌어 보세요. ‘별 잇기’에서는 두 별을 눌러 연결합니다.
- **다음으로 못 가요:** 배치 단계는 별 2개 이상, 연결 단계는 별 4개 이상이 하나로 연결되어야 합니다. 이어서 떠오른 모습, 이름, 만든 사람을 입력하세요.
- **이야기를 꼭 써야 하나요?:** 추가 이야기는 선택입니다. 이름과 떠오른 모습으로 기본 설명 두 문장이 만들어집니다.
- **기기에서 저장이 제한돼요:** 현재 탭에서 계속 만들 수 있습니다. 완료한 뒤 PNG로 보관하세요.

## 개발

순수 HTML/CSS/JavaScript입니다. 서버·설치·빌드 명령이 없습니다.
로컬 HTTP 서버가 필요하면 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 엽니다.

## 포함된 글꼴

한글 PNG 저장을 위해 Noto Sans KR Regular를 로컬 파일로 포함했습니다. 외부 글꼴 서버에 연결하지 않습니다. 글꼴은 SIL Open Font License 1.1을 따르며 원문은 `assets/fonts/OFL.txt`에 있습니다.
